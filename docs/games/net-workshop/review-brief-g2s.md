## 확인할 것

1. **테스트**: 셋 다 직접 — 실패 0. 바뀐 `tests/`를 줄마다 읽어 약해진 검사 0(판 크기 기대값이 바뀐 줄은 독립 계산인지).
2. **판 = 매트 전체**: 매트 안 어디에나(네 가장자리·창 아래) 놓기·옮기기·자석·빈 판 누르기·판 안으로 당기기(마우스·터치·키보드), 놓은 자리와 접기·저장·같은 모양 판정이 매트 어디서나 같은지, 1 cm 크기가 전보다 작아진 화면 0(여섯 크기 — 지난 값과 견줌), 어떤 전개도든(962가지 — 가장 넓은 것) 옮기지 않고 창 밖에 다 들어가는지.
3. **옆으로 옮겨 보기**: 자유 쌓기([◀][▶]·Shift+방향키·두 손가락)와 같은 모습·뜻인지 나란히, 옮기기의 모든 자리를 합치면 창에 가렸던 판이 다 보이는지, 제자리(새로 만들기·접었다 펴기·다시 들어오기·창 크기 바꾸기), 옮긴 채 놓기·끌기·돌리기·키보드 자리가 cm 그대로인지, 두 손가락 옮기기와 놓기·고르기의 헷갈림 0, 창이 판을 가리지 않는 배치(휴대폰)에서 버튼 없음, [모두 빼기] 뒤 옮긴 거리(Build: 그대로 둠).
4. **그대로**: 자석(20°·맞춤)·30° 돌리기·판정·점수·962가지·정답 노출 0·다른 화면(기준 = 지침을 맡긴 `main` 커밋 — 사이트 코드 `f55ee6b`와 같음).
5. **배치·속도**: 여섯 크기 × 보통·글꼴 흉내 × (빈 판·다 놓음·옮긴 모습·창 아래까지 놓음) 스크롤·넘침·겹침 0, 손잡이가 창·버튼을 피해 생기는지, 움직임 프레임 간격(CPU 1·4·8배). 고친 검사 CPU 4·8·12배.
6. 새로 생긴 문제, 사용자가 정해야 할 것.
