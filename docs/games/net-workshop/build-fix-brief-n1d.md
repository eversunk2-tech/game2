## 점수 규칙을 넣을 때 지킬 것 (N1c-1 · N1c-3)

- 엔진에는 일반 규칙으로 넣는다(예: 답에 "이 기기에서 한 번만 점수를 받는 답" 표시 → 시작 별과 상관없이 점수, 바로 저장). 이름·모양은 네가 정하고 `docs/engine.md`(4절 표·10절)에 적는다. 그 표시가 없는 답의 동작은 **한 글자도 달라지면 안 된다**(예시 게임·다른 단계).
- **한 모양의 점수는 어떤 길로도 한 번만**: 새로 고침, 나갔다 들어오기, 탭 두 개, 같은 판에서 돌려·뒤집어 다시 접기, 처음에 틀린 모양을 나중에 맞히기를 섞어도 두 번 받지 못한다. 처음에 예상을 틀린 모양은 그 자리에서 "접어 본 모양"이 되어 나갔다 와도 예측 점수를 다시 받을 수 없다(나가서 틀린 예상을 지우는 길이 없어야 한다).
- **모두 맞힌 쪽이 손해 보지 않는다**: 같은 모양·같은 판 나눔에서 "모두 맞힘 ≥ 일부러 틀림"을 무작위 단위 검사로 넣는다(판 나눔·순서·나가기를 섞어서). 한 판 안에서 일부러 틀려 이득 0, 35가지 한 판 모두 맞힘이 상한(지금 219점)이라는 기존 검사는 그대로 통과해야 한다. 나갔다 들어오기를 섞은 쪽이 같은 순서로 나가지 않은 쪽보다 더 받아도 안 된다.
- **화면이 실제 점수와 같다**: 머리 점수, 예상 안내("맞으면 +2" 등)·쪽지, 결과 "오늘의 솜씨" 칸 합 + 점수 줄 = "이번에 모은 솜씨 점수" = 저장된 점수 차(N1-4에서 맞춘 것 유지). 별 3개 다시 하기 판의 결과 안내 문장("별 3개를 받은 단계라 연습 점수는 없어요…")은 자유 배치에서 사실과 달라지므로 맞게 고친다(처음 접는 모양은 점수, 접어 본 모양은 0점). 5~6학년 눈높이 해요체.
- 까닭을 고르기 전에 나간 경우처럼 남는 한계가 있으면 숨기지 말고 보고에 적는다.
- 판을 넘는 탐구 총점이 달라지므로 기존 단위·e2e 기댓값이 바뀔 수 있다. 바꾼 검사마다 이유를 보고에 적는다. 단언을 지우거나 약하게 만들지 않는다.
