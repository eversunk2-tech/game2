## 확인할 것

### A. 끄는 면이 보이는가 (16-11)

1. **기준 커밋 `7096723`에서 문제를 먼저 재현한다**: 1366×768에서 자유 배치의 오른쪽 카드 칸 면을 끌어 판 쪽으로 옮기는 도중의 스크린샷 — 끄는 면이 안 보이는 것을 직접 확인(어디서부터 안 보이는지).
2. **작업 트리에서**: 같은 끌기의 도중(집은 직후, 판과 카드 칸 사이, 판 가운데, 놓기 직전)을 스크린샷으로 찍어 **직접 열어** 끄는 면이 온전히 보이는지 본다. 수치로도: 끄는 요소(또는 복제)의 화면 상자가 포인터 밑에 있고, 그 가운데 점의 `elementFromPoint`가 끄는 면이거나 그 위에 가리는 것이 없음, 잘린 넓이 0.
   - 경우: 카드 칸 → 판, 판 위의 면 → 다른 칸, 판 → 카드 칸(빼기), 찬 칸으로 끌어 거절, 놓을 수 없는 곳에서 떼어 제자리로.
   - 마우스(1366×768·1366×680)와 터치(820×1180·390×844, CDP). 끄는 동안 페이지·판 스크롤 0.
   - 끄는 면이 집은 카드와 같은 크기·색·글자인가, 같은 면이 또렷하게 두 개 보이지 않는가, 놓을 칸 강조가 보이는가.
3. **끌기 뒤 흔적**: 놓은 뒤·거절 뒤·`pointercancel`·창 밖에서 떼기·Esc 뒤에 남은 복제·`is-dragging` 클래스·`transform`·리스너가 없는가. 여러 번 되풀이해도 같은가.
4. **동작은 그대로인가**: 놓이는 칸 판정, 눌러서 놓기, 키보드 놓기, 되돌리기, 떨어진 면 안내, 6장 놓은 뒤 예상 버튼. 자유 배치 e2e 기존 검사.
5. **다른 끌기 자리**: 면 붙이기의 면 카드 → 빈 자리, 예시 게임의 카드 → 상자. `7096723`에서 끄는 도중 보였는지/안 보였는지와 지금. 엔진을 고쳤다면 예시 게임의 끌기 모습·동작이 `7096723`과 같거나 나아졌는가(나빠진 곳 0), engine.md에 적혔는가.

### B. 끝없이 돌아가는가 (17-17)

1. **한계가 없는가**: 접힌 입체를 위로 계속 끌어 180°를 넘어 한 바퀴(360°) 넘게, 아래로·왼쪽·오른쪽·대각선 네 방향도. 멈추는 곳이 없고, 한 바퀴 돌면 같은 모습으로 돌아오는가(면 자리 비교). 접는 도중(접는 정도 30%·60%)에서도 되는가(사용자가 "접는 과정이나 다 접었을 때"라고 했다).
2. **끄는 방향 = 도는 방향**: 처음 자세, 옆으로 누운 자세, 뒤집힌 자세, 대각선으로 돌린 자세 각각에서 오른쪽·위로 30px 끌었을 때 화면 가운데에 보이는 면의 가운데 점이 끈 방향으로 움직이는가(무작위 자세 여러 개). 뒤집힌 뒤 가로 방향이 거꾸로 되지 않는가.
3. **버튼·키보드**: 네 방향 버튼과 ←→↑↓가 한계 없이 돌고 회전 때문에 꺼지지 않는가. 한 바퀴만큼 누르면 제자리인가. 크게·작게는 0.5~2배에서 멈추고 꺼지는가. [처음 보기로]·`0`·Home. 버튼만·키보드만·끌기만으로 각각 입체의 여섯 면을 모두 정면으로 볼 수 있는가.
4. **보이는 모습**: 무작위 자세 수백 개 × 여러 모양(전개도·겹침·2×2)에서 면 글자·"✗ 겹쳐요"·"비어요"·●가 거울상 0인가(계산 + 스크린샷을 직접 열어 확인: 뒤집힌 자세, 대각선 자세, 한 바퀴 넘게 돌린 자세). 글자가 거꾸로(±90° 넘게) 보이는 비율. 면 밝기가 돌리는 동안 어색하게 튀지 않는가. "돌려 보면 빈 자리가 보여요" 안내가 실제 보임과 맞는가. 화면 읽기 알림이 실제 모습과 어긋나는 말을 하지 않는가.
5. **펴고 접기**: 아무 자세에서 [펴기]·막대 0 → 처음 모습, 다시 접으면 내 자세. 막대를 천천히 움직일 때 튀지 않는가(연속). 다음 문제 → 처음 보기. 자유 배치 판 → 무대 어긋남 0px.
6. **오래 써도 망가지지 않는가**: 무작위 끌기·버튼 수천 번 뒤 입체가 찌그러지거나 커지지 않는가(면 크기·직각 유지), 콘솔 오류 0.
7. **그대로인 것**: 답한 뒤 접힌 입체에서만, 답하기 전 화면 = `bf86e8c`(v1b 지침 2번과 함께 잰다), 까닭 고르는 중 노출 0(24가지 — 새 회전으로 아무 방향에서 봐도), 벌리기·휠 확대, 두 손가락 → 한 손가락, 끌기와 누르기 가르기, 멈췄을 때 또렷함, 나간 뒤 남는 것 0, 움직임 줄이기.
8. 단위 검사: 0~180 한계 검사가 **지워지지 않고** 새 결정을 고정하는 검사로 바뀌었는가.
