## 확인할 것

1. **테스트**: `npm test`, `npm run test:e2e`를 직접 실행한 결과(통과·실패·건너뜀). 건너뜀이 기기 나눔뿐인지. `git diff tests/`로 기존 검사가 약해지지 않았는지 — 지우거나 바꾼 검사 줄마다 이유가 맞는지(N1-2로 점수 기댓값이 달라진 것은 16-8과 맞는지 계산으로 확인).
2. **항목별 재측정** (지난번과 같은 방법으로, 고쳐졌다는 것을 직접 재현해 확인):
   - **N1-1 (가장 중요)**: 자유 배치에서 안 되는 모양 **24가지 모두**를 놓고 [안 될 거예요]를 고른 뒤, 까닭 칩을 고르는 동안 화면에 정답 까닭이 드러나지 않는가. 글자(`.stage-badge`·`.face-mark` 등의 "네 면이 한 점에", "겹쳐요", "비어요")뿐 아니라 표시(●, 면 색·테두리), 클래스 이름·`aria-label`·`title`·숨은 글자·`data-*` 속성, 화면 읽기용 알림(aria-live)까지 본다. 고른 뒤(맞든 틀리든)에는 보이는가. 예상을 틀렸을 때("될 거예요"로 틀림)의 흐름, 움직임 줄이기·`?fx=low`에서도 같은가. 네 크기 스크린샷을 직접 연다. 판별 단계의 까닭 고르기도 여전히 노출 0인가.
   - **N1-2**: spec 16-8과 같은가. 기획서 문장만 보고 짠 **독립 점수 계산**과 엔진을 비교한다(무작위 여러 명·여러 판). 같은 모양(돌림·뒤집기)을 다른 판에서 다시 접으면 0점, 35가지 전부 탐구 시 총점, 별 3개를 일부러 피하며 다시 해도 이미 접은 모양은 0점, 일부러 틀려 이득 없음, 노트 등록 +1·전개도 발견 +5, 별은 그대로, 결과·문장은 그대로 보임. 저장: 새로 고침 뒤에도 "처음 접음"이 유지되고 두 번 받을 길이 없는가(판 중간 새로 고침, 탭 두 개, 처음 접을 때 예상을 틀린 모양을 나중에 맞히기 등 부풀리기 시도). "기록 모두 지우기" 뒤에는 처음 상태인가. "별 3개 단계 다시 하기 연습 점수 0" 규칙·다른 단계 점수와 충돌이 없는가. 모두 맞히는 학생의 첫 차시 점수와 칭호 기준(0·40·100·180·300)을 견준 의견.
   - **N1-3**: 처음 화면·단계 지도·학습 기록·결과 복사의 도감 칩이 "n / 11"인가, 노트는 따로 "노트 n / 24"인가. 엔진 규칙을 바꿨다면 예시 게임·템플릿에 영향이 없고 engine.md에 적혔는가.
   - **N1-4**: 결과 "오늘의 솜씨" 칸 점수 합 + 점수 줄 = "이번에 모은 솜씨 점수"인가 — 까닭 설명 점수가 있는 판, 다시 하기로 0점인 판, 노트만 있는 판 등 여러 경우. 1366×680에서 칸이 잘리거나 스크롤이 생기지 않는가.
   - **N1-5**: 휴대폰(390×844) 면 붙이기에서 틀린 뒤 [펴고 다시 하기]를 누르면 앞 알림이 사라지고 면 카드·[반만 접어 보기]를 가리지 않는가.
   - **N1-6**: 표지 `transform` 검사가 선형인가(`rotate(1) ` n번 + 틀린 글자, n을 키워 시간 측정). 허용 목록이 약해지지 않았는가(지난 공격 몇 가지 + 새 공격 몇 가지 다시 시도, 올바른 표지는 통과).
   - **N1-7**: 태블릿(820×1180) 결과 화면 처음 2초의 가로 넘침이 0인가. 고친 방법 때문에 도장·색종이 연출이 어색하게 잘리거나 다른 화면(세로 스크롤, 초점 테두리, 그림자)이 잘리지 않는가.
   - **N1-8**: 1366×680 차시 끝 결과 화면 세로 스크롤 검사가 e2e에 들어갔고 실제로 그 장면을 재는가.
   - **N1-9**: 떨어진 면 판정이 한 곳인가. 판정 결과가 전과 같은가 — 6칸 고르기 전수(또는 큰 표본)로 `c517c76`의 결과·독립 계산과 비교.
3. **회귀**: 판정·수학이 그대로인가(`fold.js` 결과 불변, 자유 배치 35가지 × 방향을 독립 계산과 다시 비교). 지난 검토에서 문제없던 것이 나빠지지 않았는가: 네 단계 1366×768·1366×680·820×1180 세로 스크롤 0, 네 크기 가로 0, 48px, 알림이 조작을 가리지 않음, 답하기 전 정답 노출(판별·마주 보는 면·면 붙이기·자유 배치 예상 전), 키보드만으로 자유 배치 끝까지, 콘솔 오류 0, 예시 게임 동작.
