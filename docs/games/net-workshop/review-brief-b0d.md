# Review 서브에이전트 지침: B0d 첫 화면은 인트로 · 선생님용 안내 · 저작권 줄 · 학년 고르기 시안 A (트랙 "b0d")

## 역할과 범위

- 너는 **Review** 담당이다. Build가 [build-brief-b0d.md](build-brief-b0d.md)(맨 아래 덧붙임 1~5까지)에 따라 만든 것을 **독립적으로** 검증한다. Build와 분리된 검토자다.
- **사이트의 첫 화면과 학생이 매번 지나는 학년 고르기를 바꾸는 일이다.** "맨 위 주소로 들어오면 인트로가 나오는가", "어떤 길로도 막히지 않는가"를 먼저 본다.
- 검토 결과는 새 파일 `docs/games/net-workshop/review-b0d.md`(트랙의 작업 폴더 안) 하나. 맨 위에 판정 줄(통과 = 반드시 수정 0건 / 수정 필요). 커밋하지 않는다.
- 코드·테스트·다른 문서를 고치지 않는다. 커밋·브랜치 바꾸기·작업 트리를 바꾸는 git 명령 금지(읽기용은 된다). `npm install`·`npm ci`·내려받기 금지. 서버·실행은 네가 띄운 PID만 내린다. 작업 폴더에서만 일하고 검증 파일은 정해 준 scratchpad에만. Build의 scratchpad는 근거로 삼지 않는다(시안 그림 `design-grade/shots/`은 사용자가 고른 모습의 기준으로만 본다).

## 기준

- 사용자의 말과 결정: [spec-grade6.md](spec-grade6.md) **15-13**(첫 화면 인트로, [선생님용 안내], 안내 페이지의 카드 → 학년 고르기, 예시 게임 카드 빼기, `?intro=0`, 개발용 주소도 같게), **15-14**(저작권 줄 — 학년 고르기·학년 화면·선생님용 안내 페이지 맨 아래, 그 밖에는 없음), **15-15**(학년 고르기 시안 A "큰 두 칸"), 15-12(안내글의 뜻)
- [build-brief-b0d.md](build-brief-b0d.md) 전부, [common-rules.md](common-rules.md), [docs/engine.md](../../engine.md), [docs/design/spec.md](../../design/spec.md)
- review-b0b.md의 B0b-1·B0b-2(이 가지에서 고침)

기준 `20770eb`(B0b 빌드 바탕 — 이미 사이트에 올라간 `0b1bb57`과 코드가 같다)와 `track/b0d`의 마지막 Build 커밋 사이의 변경 전부(그 사이 코디네이터가 `main`의 문서를 합친 커밋은 대상 아님). Build의 최종 보고는 코디네이터가 요약해 전한다 — **확인 대상이지 근거가 아니다.**

## 확인할 것

1. **테스트**: `npm test`, `E2E_PORT=<네 포트> npm run test:e2e -- --workers=4`를 보통과 글꼴 흉내로 직접 실행 — 실패 0. `git diff 20770eb..HEAD -- tests/`를 줄마다 읽어 **약해진 검사 0**(뜻이 바뀐 줄은 사용자 결정에서 온 것인지).
2. **첫 화면·길 (가장 중요)**: GitHub식(하위 경로 `/game2/`)과 Cloudflare식(맨 위 경로 `/`, `.html`을 뺀 주소로 308 — 쿼리 그대로) 두 흉내 서버(scratchpad — 저장소에 더하지 않는다)에서:
   - 맨 위 주소 → 인트로가 **바로**(다른 화면이 한 프레임도 보이지 않게 — 필름처럼 찍어 확인), 맨 위 주소 + 수업 옵션(`?lesson=cube`·`?area=blocks`·`?grade=6`·`?stage=…`·`?intro=0`·`?fx=low`·`?sound=off`).
   - 옛 주소 `net-workshop.html?…` 그대로, 저장 열쇠·값 그대로이고 맨 위 주소와 옛 주소 사이에 기록이 이어짐(같은 출처).
   - [입장하기] → 학년 고르기 → [선생님용 안내] → 안내 페이지 → "입체도형 공방" 카드 → **학년 고르기(인트로 없이)**, 안내 페이지의 [← 학년 고르기], 학년 고르기의 [← 처음으로] → 인트로, 뒤로 가기·새로 고침.
   - 예시 게임은 안내 페이지 목록에 없고 주소(`sample-divisor-sort.html`)로는 열림.
   - 모든 길에서 응답 400 이상 0·콘솔 오류 0·다른 출처 요청 0.
   - 개발 서버(`npm run dev` — 네 포트)에서 맨 위 주소 → 인트로, `teacher.html` → 안내 페이지(덧붙임 5).
3. **학년 고르기 시안 A**: 사용자가 고른 시안 그림(`…/scratchpad/design-grade/shots/A-1366.png`·`A-820.png`·`A-390.png`)과 실제 화면을 나란히 놓고 같은 모습인지(직접 연다). 학년 설명이 사용자 문장 그대로, 큰 숫자는 화면 읽기에서 숨김, "여기부터!"·별 수, 칭호 한 줄·[놀이 방법]·[학습 기록], 오른쪽 그림·소개 두 줄 없음. 다섯 크기(1366×768·1366×680·1024×768·820×1180·390×844) + 960×680·1024×600 × 보통·글꼴 흉내에서 스크롤·잘림·겹침 0, 카드 크기·비율(Build: 1366×768 582×380·42.2%). 손가락 48px, 대비, Tab 순서, 키보드로 학년 고르기.
4. **[선생님용 안내] 버튼**: 학년 고르기에만, 작고 눈에 덜 띄게(학년 카드보다 앞서 보이지 않음), 48px·대비·Tab 순서(학년 카드 → 놀이 방법 → 학습 기록 다음), 마우스·터치·키보드, 같은 탭.
5. **저작권 줄**: 학년 고르기·학년 화면(영역 카드 — 학년 둘 다)·선생님용 안내 페이지 맨 아래에 **글자 그대로** `© 2026 PSC. All rights reserved.`, 대비 4.5:1 이상, 카드와 겹침 0·새 스크롤 0. **인트로·단계 지도·플레이·결과·놀이 방법·학습 기록·수업 주소 화면에는 없음**(화면마다 확인).
6. **선생님용 안내 페이지**: 제목, 안내글(맨 위 주소로 열면 인트로), 카드 하나(→ `net-workshop.html?intro=0`), 주소 옵션 목록(`?intro=0`·`?grade`·`?area` 포함 — 설명이 engine.md 8절과 같은지), 기록 안내의 "주소마다 따로"와 두 주소가 정확한지, 다섯 크기에서 넘침 0.
7. **불변**: 기준 `20770eb` 빌드와 견줘 학년 고르기·안내 페이지·저작권 줄 말고는 모든 화면(인트로·학년 화면의 카드·단계 지도·모든 단계의 첫 화면·결과·학습 기록·예시 게임)이 픽셀까지 같은지. `intro`·`teacherGuide`·`footer`를 쓰지 않는 게임(예시 게임·템플릿)의 경로가 코드로도 그대로인지.
8. **B0b-1·B0b-2**: 문서·주석이 실제 동작과 맞는지(미리 받기가 실패하면 그 페이지에서는 다시 받지 못하고 [새로 고침]으로 풀림), `?fx=low`·움직임 줄이기에서 "불러오는 중" 점이 멈추는지(보통에서는 움직임).
9. **c4와 합칠 때**: `git merge-tree --write-tree`로 `track/c1`(지금 커밋)·`main`과 줄 충돌, 합친 결과를 scratchpad에 풀어 단위·인트로·학년 고르기 e2e를 돌려 본다(`E2E_PORT`를 꼭 준다) — c4가 [입장하기]·인트로를 바꾼다.
10. **코드·문서**: 지침 밖 수정(`rewards-view.js` `compact` — 코디네이터가 받아들임)이 다른 화면의 칭호 카드를 바꾸지 않는지, `h()`만·`innerHTML` 없음·이모지 없음, `README.md`·`docs/engine.md`·`docs/dev-guide.md`가 코드와 맞는지.
11. **느린 기기 검사**: 새로 만들거나 고친 검사를 CPU 4·8·12배로 돌려 값 실패 0.
12. 새로 생긴 문제, 사용자가 정해야 할 것(선택지와 추천).
