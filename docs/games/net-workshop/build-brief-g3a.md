## 만들 것 (G3a)

1. **원기둥 바탕**: `grade6/cylinder.js`(순수 — 모델 · `checkCylinder` · `toStrips`, plan 3-0과 spec 6-2·6-3대로. 띠 폭은 그 문항의 원주율로 정하는 자리를 만들어 두되, 1·2단계는 원주율이 적히지 않으므로 참값 π). `view3d.js`에 `kind: 'cylinder'` 갈래(띠 36개 · 0.6px 겹침 · 원 · 윤곽선 띠 · `raster` — **기본 갈래(정육면체·직육면체·각기둥)는 한 글자도 바꾸지 않는다**, 원기둥이 다른 갈래로 빠지지 않게). 말기는 지금의 `foldNet`으로(`fold.js`는 고치지 않음). 겹침·빈 곳·크기 다른 원·사다리꼴 표시(plan 3-0 표, 그림 설명은 `roll-results.png`와 같은 뜻).
2. **1단계 `cylinder-parts` "밑면과 옆면"**(plan 3-1): 밑면 두 개 고르기 2문항(선 것 1 · 눕힌 것 1, 1.5배) + 높이 고르기 1문항, 맞히면 ○△ 표시와 펼침. 옆면 띠 36개 = 한 면(어느 띠를 눌러도 옆면 전체, Tab·화면 읽기는 한 번).
3. **2단계 `cylinder-judge` "원기둥이 될까?"**(plan 3-2): 5문항(되는 것 2 = 흔한 꼴 1 + 낯선 꼴 1 / 안 되는 것 3 = 같은 쪽 · 크기 다름 · 사다리꼴), 판의 절반쯤은 안 되는 것 하나를 낯선 꼴로(15-20 G1-4 원칙), 예상 → (안 되는 것을 맞혔으면) 까닭 → 말아서 확인, 사다리꼴은 말지 않고 표시, 까닭 칩은 4절 끝의 말, 같은 1 cm(`CYL_FIT`), 정답 노출 0(plan 3-2 "정답 노출" 줄 — 모든 옆면을 같은 방식으로 그림, 꼴·크기·자리만 보고 맞히는 규칙을 시드 수백 개로 재서 찍기 50%보다 크게 높지 않게).
4. **영역 둘레**(plan ⑥ 가운데 G3a 몫): 원기둥 차시 `cylinder`(단계 둘) 등록 → 원기둥 영역 카드가 열림, 단계 지도, 단계 그림, 놀이 방법(1·2단계 줄만), 학습 기록 tag, 6학년·내 공방 별 합계(단계 둘만큼 — 네가 세어 보고), 차시 시간 칩(단계 둘의 어림 — 네가 정하고 까닭 보고), 원기둥 묶음 늦게 불러오기(처음 받는 크기 전·후 보고). 원기둥 "준비 중"을 고정한 검사는 **뜻이 바뀐 검사**(열린 것을 고정하도록 고치고, 준비 중 카드의 동작이 엔진 검사로 여전히 지켜지는지 확인해 보고).
