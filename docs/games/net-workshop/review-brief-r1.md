# Review 서브에이전트 지침: R1 쌓기나무 판 돌림판식 돌리기 + S3-1·S3-2 (트랙 "blocks")

## 역할과 범위

- 너는 **Review** 담당이다. Build가 [build-brief-r1.md](build-brief-r1.md)(덧붙임 S3-1·S3-2 포함)에 따라 만든 것을 **독립적으로** 검증한다. Build와 분리된 검토자다.
- 검토 결과는 새 파일 `docs/games/net-workshop/review-blocks-r1.md`(트랙의 작업 폴더 안) 하나. 맨 위에 판정 줄(통과 = 반드시 수정 0건 / 수정 필요). 커밋하지 않는다.
- 코드·테스트·다른 문서를 고치지 않는다. 커밋·작업 트리를 바꾸는 git 명령 금지(읽기용은 된다). `npm install`·`npm ci`·내려받기 금지. 서버·실행은 네가 띄운 PID만 내린다. 작업 폴더에서만, 검증 파일은 정해 준 scratchpad에만. Build의 scratchpad는 근거로 삼지 않는다(계획의 시제품·알지오매스 관찰 `plan-rotate/`는 기준 모습으로만).

## 검토 대상

`31f6ed2`(지금 사이트)와 `track/blocks`의 마지막 커밋 사이의 변경 전부. Build의 최종 보고는 코디네이터가 요약해 전한다 — **확인 대상이지 근거가 아니다.**

## 확인할 것

1. **테스트**: `npm test`, `E2E_PORT=<네 포트> npm run test:e2e -- --workers=4`를 보통과 글꼴 흉내로 직접 — 실패 0. `git diff 31f6ed2..HEAD -- tests/`를 줄마다 읽어 약해진 검사 0(바뀐 줄이 "화면 기준으로 구르는" 옛 뜻을 새 뜻으로 바꾼 것인지).
2. **돌림판식 — 독립 계산**: 기획서·계획 문장만으로 짠 계산(가로 1px = 판 0.5°·끝없이, 세로 1px = 높이 0.5°·0~90°에서 멈춤, 중심은 판 가운데, 버튼 판 45°·높이 15° 눈금, 방향키, 0/Home)과 실제 화면(쌓기나무 꼭짓점의 화면 자리)을 무작위 끌기·버튼·키 수천 번에서 견준다. **판이 기울지 않음**(화면에서 쌓기나무 세로 모서리가 곧음 — 끄는 도중·놓은 뒤·움직임의 모든 프레임), 판 밑으로 가지 않음.
3. **정해진 자세 불변**: 처음 보기·[위][앞][옆]·뒤·왼쪽 등이 `31f6ed2`와 같은 모습(화면 비교·수치), 답하기 전 정답 노출·돌려 보기 잠금이 단계마다 그대로.
4. **손맛(알지오매스와 견줌)**: 계획의 알지오매스 관찰(`plan-rotate/shots/algeo-sheet.png` 등 — 가로 끌기는 제 세로축 둘레, 세로 끌기는 높이만, 수평 유지)과 같은 느낌인지 스크린샷·필름으로 직접 보고 의견. 같은 끌기에서 지금 / 새 비교 그림을 네가 따로 만들어 직접 연다.
5. **수단**: 마우스·터치(한 손가락 돌리기, 두 손가락 확대만)·키보드·조작판 버튼, 누르기(쌓기)와 끌기 가르기 8px, 끈 직후 첫 누르기, 한도에서 버튼 꺼짐(화면 읽기 이름·상태), 0.5~2배.
6. **전개도 쪽 0줄·불변**: `orbit.js`·`view3d.js`·`fold.js`·전개도 부품·`grade6/**`·엔진·`main.js` 변경 0(코드로), 정육면체·직육면체 차시의 돌려 보기 동작이 `31f6ed2`와 같음(같은 끌기의 화면 비교).
7. **S3-1**: 시드 2,000개 이상으로 "층별 모양만 보고 알아내기" 개수 보기에서 꼴만 보는 규칙들(한가운데 수·끝 수·간격 등)이 맞히는 비율이 찍기(25%)보다 크게 높지 않은지, 정답 자리 고름, 함정(맨 위층 빠뜨림·1층 칸 수)이 여전히 나오는지, 정답 노출 0.
8. **S3-2**: 앞·옆을 바꿔 칠했을 때·다 칠했을 때 힌트가 "0층"을 말하지 않고 4절 "앞과 옆"의 뜻에 맞는지(문장을 직접 읽음). 4차시 수 쓰기의 같은 문장은 범위 밖으로 둔 것이 맞는지.
9. **배치·문장**: 여섯 크기(1366×768·1366×680·1024×768·960×768·820×1180·390×844) × 보통·글꼴 흉내에서 스크롤·넘침·겹침(놀이 방법이 두 줄이 된 곳 포함), 새 안내 문장(해요체·사실과 맞음), 화면 읽기 이름.
10. **느린 기기**: 돌리는 동안 프레임 간격 CPU 1·4·8배, 새로 만들거나 고친 검사 CPU 4·8·12배 값 실패 0.
11. **합칠 때**: `git merge-tree --write-tree`로 `main`·`track/cuboid`(G1b — 재검토 중)와 충돌.
12. 새로 생긴 문제, 사용자가 정해야 할 것.
