# Build 지침: G2s 각기둥 4단계 판을 초록 판 전체로 · 가려진 부분은 옆으로 옮겨 보기 (트랙 "cuboid" 작업 폴더)

## 역할

너는 G2r을 만든 **Build** 담당이다. 사이트에 올라간 각기둥 4단계 자석 판(`f55ee6b`)을 사용자의 새 요청대로 고친다. 검증은 별도 Review가 한다.

사용자의 말(2026-10-25, [spec-grade6.md](spec-grade6.md) 15-32 — 그대로): "흰색 점선 테두리 안에서만 면이 배치가 되도록 되어 있어서 불편해. 초록색 판을 다 활용할 수 있도록 수정해줘. 그리고 전개도 완성 모습 그림에 가리는 부분은 옆으로 이동 버튼으로 이동할 수 있도록 해주고..."

## 만들 것

1. **놓는 곳 = 초록 판(매트) 전체**: 흰 점선 테두리 영역(지금의 판 크기 cm) 제한을 없애고 매트 안 어디에나 놓기·옮기기·자석·판 안으로 당기기(G2r-7)가 되게. 점선 테두리는 지우거나, 남긴다면 놓기를 막지 않는 안내로만. 1 cm의 화면 크기는 지금보다 작아지지 않게(커질 수 있으면 커지게 — G2r-3 육각기둥 옆면 폭 39~50px도 함께 재서 보고). 다 놓은 넓은 전개도(육각기둥 꽃 꼴 등)가 매트에 들어가는지, 접기·저장·같은 모양 판정이 매트 어디에 놓아도 같은지.
2. **"만들 각기둥" 창(완성 모습 그림)에 가려진 판은 옆으로 옮겨 보기**: 자유 쌓기의 판 옮기기(`blocks/play-free-build.js` — [◀][▶]·Shift+방향키·두 손가락, 결정 15-19의 9)와 같은 모습·뜻으로 판(놓인 면과 함께)을 옆으로 옮겨 가려진 곳을 본다. 창이 판을 가리지 않는 배치(세로 태블릿·휴대폰 등)에서는 버튼이 없거나 꺼짐. 새로 만들기·접기 뒤 펴기·다시 들어오기에서 제자리, 놓기·끌기·돌리기·자석과 헷갈림 0, 키보드·터치·마우스 모두. 창 아래에도 면을 놓을 수 있는지(옮겨서 놓기)와, 창 아래로 끌어간 면이 보이지 않게 되지 않는지.
3. 그대로: 자석(길이가 달라도 붙음, 20°, 덜 움직이는 맞춤), 30° 돌리기, 빈 판 누르기, 판정·점수·도장·962가지, 정답 노출 0, 다른 모든 화면.
