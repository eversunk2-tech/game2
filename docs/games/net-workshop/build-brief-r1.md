# Build 서브에이전트 지침: R1 쌓기나무 판을 알지오매스처럼 돌리기 — 돌림판식 (트랙 "blocks")

## 역할

너는 쌓기나무 영역의 **Build** 담당이다. 사용자의 수정 요청([spec-grade6.md](spec-grade6.md) **15-18·15-19**)의 첫째 — **쌓기나무 판의 돌리기**를 바꾼다. 계획은 [plan-rotate-free.md](plan-rotate-free.md) 4절·6절(R1). 자유 쌓기(F1)는 다음 Build다. 검증은 별도 Review 서브에이전트가 한다.

사용자의 말: "쌓기나무 쌓는 받침이 되는 판을 여러 방향으로 돌려볼 때 한쪽으로 너무 기울어 지는 경우가 많고 원하는 느낌으로 돌려지지가 않아. 알지오매스 사이트는 … 수평이 맞게 앞, 옆의 모습도 돌리면서도 확인하는게 잘 돼 … 알지오매스처럼 돌리는 받침판이 돌려질 수 있도록 관련 로직을 수정해줘" · "5학년 전개도는 그대로 둬도 좋아" · "쌓기나무 판의 돌리기만 수정해줘."

## 사용자 결정 (15-19)

- **돌림판식**(알지오매스와 같음): 가로 끌기 = 판이 제 세로축 둘레로 끝없이 돎, 세로 끌기 = 내려다보는 높이만 바뀜. 화면에서 판의 세로축이 늘 곧다(기울지 않음).
- 돌기의 중심 = **판 가운데**(누른 곳과 상관없음). 위아래 한도 = **수평 ~ 바로 위**(판 아래로 가지 않음).
- **쌓기나무 무대에만**(놀이터·모든 차시 단계·도전, 다음 Build의 자유 쌓기). **전개도 입체(5학년 정육면체·직육면체, 6학년 각기둥)는 한 글자도 바꾸지 않는다** — `orbit.js`·`view3d.js`는 0줄 변경.

## 할 일 (계획 4-1~4-3, 6절 R1 그대로)

1. 새 모듈(계획 4-3 — 예: `blocks/turn-view.js`)에 돌림판식 보기 상태(가로 각·높이 각)와 끌기·키보드·조작판 버튼의 규칙(1px = 0.5°, 문턱 8px, 관성 0 — common-rules 4절 값 그대로, 버튼은 판 45°·높이 15° 눈금, 한도에서 높이 버튼 꺼짐), 0·Home = 처음 보기. 쌓기나무 무대(`block-view.js`)가 이것을 쓰게.
2. 처음 보기·[위][앞][옆]·그 밖의 정해진 자세(지금 `POSES`)는 지금과 같은 모습(계획 6절 검사 ① — 1e-12 안).
3. 끄는 동안·놓은 뒤 판이 기울지 않음(계획 6절 검사 ② — 무작위 끌기 10,000번 뒤에도 화면 오른쪽 방향의 높이 성분 0, 높이 각 0~90°), 화면에서 쌓기나무 세로 모서리가 곧음(e2e).
4. 답하기 전 정답 노출·돌려 보기 잠금(spec-grade6 5절, 계획 4-2)은 지금 그대로 — 잠근 단계에서는 돌리기 자체가 없다.
5. 쌓기나무 놀이 방법·조작 안내 문장이 새 돌리기에 맞게(예: "옆으로 끌면 판이 돌고, 위아래로 끌면 내려다보는 높이가 바뀌어요" — 해요체).
6. 계획 3절의 "지금 기우는 까닭" 수치를 새 방식으로 다시 재서 보고(오른쪽 120px 끌기 31.5° → 0° 등, 무작위 2,000판).

## 반드시 지킬 것

- [common-rules.md](common-rules.md) 전부. 터치(한 손가락 돌리기·두 손가락 확대)·마우스·키보드·조작판 모두 같은 규칙. 누르기(쌓기)와 끌기(돌리기)를 가르는 8px, 끈 직후 첫 누르기가 먹히는 것(지금 검사) 그대로.
- **불변**: 기준(`main`) 빌드와 견줘 쌓기나무 무대의 처음 화면·정해진 자세·판정·점수·저장, 그리고 **전개도 차시 전부(정육면체·직육면체·각기둥)의 돌려 보기 동작**이 그대로. 전개도 쪽 기존 검사가 한 줄도 바뀌지 않고 통과.
- 다섯 크기 + 960×768 × 보통·글꼴 흉내에서 배치 그대로(돌리기 버튼·안내 글 손질만). 느린 기기: 돌리는 동안 프레임 간격 CPU 1·4·8배.
- 브라우저 검사는 느린 기기를 견디게, `waitForTimeout`·`retries` 금지. 끝내기 전에 CPU 4·8·12배로 새로 만들거나 고친 검사 값 실패 0.
- 테스트: `npm test`, `E2E_PORT=5352 npm run test:e2e -- --workers=4`, `E2E_PORT=5352 E2E_WIDE_TEXT=font npm run test:e2e -- --workers=4` 모두 실패 0.
