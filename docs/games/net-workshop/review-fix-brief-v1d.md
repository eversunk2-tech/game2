## 확인할 것

1. **테스트**: `npm test`, `npm run test:e2e` 직접 실행(통과·실패·건너뜀). `git diff tests/`에서 "25% 미만에서 줄어든다"를 기대하던 검사가 새 결정을 고정하는 검사로 바뀌었는지, 지워진 단언이 없는지.
2. **V1b-1 (가장 중요) — 접는 도중에도 똑같이 도는가**: 지난번과 같은 방법으로 접는 정도 1·5·10·20·24·25·30·60·100%에서 —
   - 100px 끌기의 각도(50°여야), 좌우 버튼 한 번(30°)·위아래 버튼 한 번(15°)·방향키 한 번(15°)
   - 한 방향으로 880px(440°) 끌기: 걸음마다 같은 각도, **튀는 걸음 0**, 처음에서 얼마나 멀리 가는가(뒤쪽·아래쪽이 보이는가), 720px에서 제자리. 여덟 방향, 마우스·터치, 네 크기
   - 뒤집힌 자세에서 끄는 방향 = 앞면이 움직이는 방향
   - 좌우 버튼 12번·위아래 24번·방향키 24번이면 제자리
   - 크게·작게 배율이 접는 정도에 따라 줄지 않는가
   지난 값(10%: 20°·72° 한계·142° 튐, 20%: 40°·144°·76°)과 나란히 표로.
3. **0을 지날 때**: 막대 0 = 처음 모습(무대 변환이 답하기 전과 같음, 펼친 채 돌린 것만 남음), 다시 올리면 내 자세. 그 사이의 움직임을 프레임 단위로 잰다: 길이(약 0.2초), 한 프레임의 최대 자세 변화, 끝 상태. 스크린샷 여러 장을 이어 직접 본다 — 자연스러운가, 두 번 튀지 않는가.
   - 괴롭히기: 막대를 0 ↔ 1~5 사이에서 빠르게 왔다 갔다, 잇는 움직임 도중에 끌기·버튼·[접어 보기]·[펴기]·[처음 보기로]·다음 문제·[펴서 고치기]·단계에서 나가기. 끝 상태가 맞는가, 나간 뒤 타이머·rAF·리스너 0, 콘솔 오류 0.
   - [펴기]·[접어 보기] 움직임과 함께 볼 때(내 자세가 있는 채로) 어색하지 않은가. 움직임 줄이기·`?fx=low`에서는 바로 바뀌는가.
   - 막대를 천천히 0 → 100으로 올릴 때 내 자세가 엉뚱하게 흔들리지 않는가(지난번 25% 이상에서와 같은 정도인가).
