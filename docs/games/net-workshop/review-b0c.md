## 6. 인트로 모습 (스크린샷을 직접 열어 본 의견)

직접 연 것: 1366×768·1366×680·1024×768@2·820×1180@2·390×844@3·844×390@3·1920×1080@1(움직임 줄이기), 처음 움직임 필름 모음(CPU 1·8배 각 7장), 느린 망 필름 모음(지금·B0c 각 17장)과 낱장 2장(지금 첫 장, 그림을 막은 3초), 리본 확대 1장, DPR 2 얼굴 확대 2장, 처음 화면 세 빌드 나란히 1장, 그림 격자 5장.

- **진짜 게임 인트로 느낌이 난다**: 밝은 하늘과 도형 마을, 두 아이가 양옆에서 보고, 가운데 위에 큰 금빛 입체 제목이 떨어져 튀고, 리본 위 흰 부제가 톡, 금빛·파란 테의 두꺼운 [입장하기]가 올라와 숨 쉰다. 별 반짝임·빛줄기·떠오르는 작은 입체가 은은하다. 사용자가 보여 준 참고 이미지의 분위기(밝고 반짝이는 큰 입체 제목, 눈에 띄는 버튼)와 맞는다.
- **선명도**: 크롬북(0.474배)은 또렷. DPR 2의 1366×1024(1.26배)·1920×1080(1.33배)에서 얼굴 선·눈동자는 또렷하고 먼 배경은 원본부터 부드럽다(늘려서 생긴 흐림으로 보이지 않음). 늘어난(비율이 바뀐) 그림 0, 이음매 0. 꽉 채우기 12기기 모두 띠 0%라 하늘색과 그림의 경계가 보이는 곳이 없다.
- **카드(태블릿 세로 820×1180)**: 카드 796×448이 화면 가운데에 있고 위아래 약 62%는 같은 그림을 흐리게 깐 바탕(위는 파랑, 아래는 베이지·회색이 번진 색) + 가장자리 어둡게. 둥근 모서리·흰 테·은은한 파란 빛이 깔끔하고 [입장하기]가 카드 아래 가장자리에 걸친다. 제목 폭 341px, 부제 14.3px로 읽힌다. 규칙대로이지만 학급 태블릿을 세로로 쓰면 그림이 화면의 3분의 1 남짓이라 "꽉 찬 게임 화면" 느낌은 덜하다(참고 B0c-4).
- 어색한 곳: 없음. 다만 느린 망에서 [입장하기]가 나온 뒤(2.7초) 제목 그림이 올 때까지(9.8초) 하늘·배경과 버튼만 있고 게임 이름이 없다(참고 B0c-3), 그림을 끝내 못 받으면 게임 이름이 화면에 없다(참고 B0c-2).

## 8. 언제 보이나·길·접근성

- 주소: `?stage=`·`?lesson=`·`?area=`·`?grade=`가 있으면(값이 비거나 틀려도) 인트로 없이, `?unlock=all`·`?sound=off`·`?seed=`·`?fx=low`만 있으면 인트로 — e2e 17가지 주소 + 단위 13가지. [입장하기] 마우스·터치(태블릿 기기)·Enter·Space → 학년 고르기, 학년 고르기 맨 위 왼쪽 [← 처음으로] → 인트로(다시 [입장하기]에 초점), 다른 화면의 [처음 화면]은 학년 고르기로. 한 차시 주소 화면에는 [← 처음으로] 없음.
- 새로 고침: 인트로부터(주소에 수업 값이 없으므로 — 설계대로). 게임 모음 → 게임 → [입장하기] → 뒤로(게임 모음) → 앞으로: 게임이 처음부터 다시 열려 인트로. 이상한 화면·오류 0(`tools/nav.mjs`). 앱은 주소 기록을 쓰지 않는다(전과 같다).
- 소리: [입장하기]에 `unlock` 효과음(1175·1568 Hz), `?sound=off`면 0(e2e). 인트로 동안 머리의 게임 이름·칭호 칩은 숨고 [소리] 버튼만 오른쪽 위.
- 접근성: h1 "입체도형 공방"(제목 그림의 대체 글) · 부제는 글자(리본 위 SVG는 `aria-hidden`, 같은 글이 화면 읽기용) · [입장하기]는 진짜 `button`이고 처음 초점 · 배경·별·떠오르는 입체·흐린 바탕은 `aria-hidden` — 화면 읽기 트리는 제목·부제·버튼 셋(e2e 스냅샷). Tab 차례 [소리] → [입장하기]. 초점 표시는 노랑 후광 + 잉크 선.
- 대비(직접 계산): 부제 흰 글자/남색 테두리 15.6:1, 버튼 잉크 글자/금빛 세 색 13.8·11.1·9.6:1.
