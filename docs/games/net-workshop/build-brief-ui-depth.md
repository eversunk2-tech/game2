## 지켜야 할 모습 (사용자 결정 + 옮긴 규칙)

1. **누를 수 있는 UI 틀**에 적용한다: 모든 버튼(주 · 보통 · 돌아가기 · 작은), 학년 · 영역 · 단계 카드, 탭, 놀이 화면의 도구 버튼과 띠 버튼, 답 버튼.
   - **쉴 때**: C의 면 색(주 = 파랑 면, 보통 = 옅은 파랑 면, 카드 = 흰 면 + 옅은 선) + 은은한 그림자. 출발 값은 "모두의 배움터"의 `0 1px 2px` 5%다.
     - 이 앱의 크림 바탕에서 너무 약하면 두 겹(닿는 1px + 옅은 확산)으로 조절한다.
     - 그림자 색은 잉크 색조를 아주 옅게 쓴다. 검정 단색 두께는 쓰지 않는다.
   - **마우스를 올리면**: 2px 떠오른다(큰 카드는 4px까지). 그림자는 `0 6px 16px -4px` 8% 안팎으로 커진다. 0.2초(큰 카드 0.3초).
   - **누르면**: 면이 조금 진해지고 제자리로 내려앉는다. 태블릿은 올림이 없으니 누름이 손맛이다. 아래 두께는 쓰지 않는다.
   - **움직임 줄이기 · `?fx=low`**: 떠오르지 않는다. 그림자 · 색 변화만 둔다.
   - 초점(키보드)은 지금처럼 또렷하게 둔다(잉크 3px + 노랑 후광).
   - 비활성 · 잠김은 C의 옅은 종이 + 점선으로 한다.
2. **읽는 판**(차시 판 · 작업 지시서 · 증명서 · 매트 둘레 · 정보 막대): C대로 흰 면 + 옅은 선으로 한다. 그림자는 없거나 아주 옅게 둔다. 밀린 그림자(`--sheet`)는 없앤다.
3. **잠깐 뜨는 것**(알림 · 색 고르기 · 이름표 등): 부드러운 뜬 그림자를 쓴다. 잉크 테두리 + 아래 4px는 없앤다.
4. **칩 · 꼬리표**: 납작한 면으로 한다. "여기부터!"는 바로 선(기울이지 않은) 파랑 꼬리표다(C).
5. **[입장하기]**:
   - 노란색 계통의 면에 **파란 테두리**를 두고, 글자는 잘 읽히게(대비 4.5 이상) 한다.
   - **아래로 덧붙은 남색 두께는 없다.** 은은한 그림자를 두고 올리면 살짝 떠오른다.
   - 크기 · 자리 · 큰 화면 배율 · 손 피하기 · 초점 · 움직임 줄이기 규칙(15-11 등)은 그대로다. 반짝임 · 숨쉬기 움직임도 지금 그대로 둔다.
6. **범위 밖**(사용자 결정 "버튼·카드 같은 틀만"): 전개도 면 · 쌓기나무 · 면 카드 · 상자 카드 · 입체 그림 · 원기둥 면처럼 학습 내용의 선과 모양은 그대로 둔다. 바탕 모눈도 그대로다.
7. **자리 · 크기는 바꾸지 않는다.** 테두리 두께(px)는 그대로 두고 색만 바꾼다(투명 포함). 레이아웃이 1px도 움직이지 않게 한다.
8. **글자 대비** 4.5 이상(큰 글자 3 이상), **누르는 곳 48px** 그대로.
   - C는 "모양만 보고 누를 수 있음"이 약했다(가장자리 대비 1.1~1.6 — plan 3-5). 은은한 그림자를 더한 뒤 같은 방법으로 다시 잰다.
   - 아이가 누를 수 있는 것을 알아볼 수 있는지(면 색 + 그림자 + [시작 ▶] 같은 표시)를 시안에서 보이고 수치로 적는다.
9. **성능**: 움직임은 `transform`만 쓴다.
   - 그림자를 바꾸는 방법(바로 바꾸기 / 가상 요소의 투명도 전환 등)은 네가 고르고 까닭을 적는다.
   - 흐림 반경은 20px 이하로 한다. `?fx=low`에서는 흐림 없는 그림자만 쓴다(plan 3-5 ④의 안전판).
