## 반드시 고칠 것

1. **F1-1 폭 901~1000px 가로 화면(960×768 등)에서 펼친 "위에서 본 판"이 잘리고, 판 옮기기로 못 보는 칸이 남는다.** 펼치는 칸의 자리와 옮기기 방향을 폭이 아니라 **매트(무대)의 모양**으로 정한다 — 가로가 긴 매트는 크롬북처럼 왼쪽 위 + 옆으로 옮기기, 세로가 긴 매트는 세로 태블릿처럼 아래 + 위아래로 옮기기(사용자가 본 두 모습 그대로 — 새 모습을 만들지 않는다). 낮은 매트에서도 14×14 판이 잘리지 않게(칸 크기 또는 제목 줄 — 칸은 24px 아래로 줄이지 않는 것을 먼저 해 보고, 줄여야 하면 몇 px인지 보고). Review가 잰 크기: 960×768·1000×768·1000×700·900×700·960×600·1024×600.
2. **F1-2 휴대폰 390×844에서 [위·앞·옆 모양] 그림이 양쪽 28px씩 잘린다**(왼쪽은 밀어도 안 보임). 휴대폰에서 그림 칸을 줄이거나 세 그림을 줄바꿈하고, 넘칠 때는 왼쪽 맞춤으로 밀어 볼 수 있게. 360×780에서도 잘리지 않게(필수 크기는 아니지만 흔한 휴대폰). 같은 휴대폰에서 위에서 본 판(48px 칸)이 양쪽 7~9px 잘리는 것도 함께 본다.
3. **F1-3 세로 태블릿 820×1180에서 알림이 띠의 버튼 넷을 약 3초 가린다**(common-rules 6). 좁은 배치에서는 알림을 매트 안 아래쪽이나 띠와 겹치지 않는 자리에 둔다. 휴대폰도 함께 본다(차시 단계와 같은 정도면 된다).

## 고치면 좋음(함께 고친다)

4. **F1-4** 키보드로 [위에서 본 판]·[색]을 펼치면 초점이 펼친 판의 고른 칸·지금 색으로 간다(또는 DOM 차례를 버튼 바로 뒤로). [색] 칸은 Escape로 닫히고 초점은 [색] 버튼으로 돌아온다. `aria-controls`·`aria-expanded`.
5. **F1-5** 화면 읽기 문장의 "9은" → `josa()`로 "9는"(e2e 고정 문장도 함께).
6. **F1-6** 제목 글꼴로 그리는 버튼·제목의 "·"(U+00B7) → "ㆍ" 또는 띄어쓰기(common-rules 7).
7. **R-f** `docs/engine.md:308`의 자유 쌓기 저장소 설명을 코드(`play-free-build.js:57-78` — 같은 열쇠 모양으로 따로 만든 저장소)와 맞게 한 줄 고친다.
8. (자연스럽게 되면) R-b 가로 태블릿 1024×768에서 펼친 칸이 판의 "앞" 글자를 반쯤 가리는 것.

## 검사

- 배치 e2e에 더한다: **960×768(보통·글꼴 흉내)**, "판 옮기기의 모든 자리를 합치면 196칸(휴대폰 36칸)이 다 보인다", **휴대폰 [위·앞·옆 모양] 켠 장면**(잘림 0), **세로 태블릿 알림 장면**(알림 밑 버튼 0). 키보드 초점·Escape 검사.
- 셋 다 실패 0: `npm test`, `E2E_PORT=5352 npm run test:e2e -- --workers=4`, `E2E_WIDE_TEXT=font E2E_PORT=5352 npm run test:e2e -- --workers=4`. 새로 만들거나 고친 검사는 CPU 4·8·12배로 미리 본다.
- 다섯 크기 + 960×768에서 처음·펼침·끝까지 옮김·위앞옆·알림 그림을 scratchpad `build-f1/shots-f1b/`에 남긴다.

## 덧붙임 1 (2026-10-19) — 재검토가 찾은 것

- **F1b-1 반드시 고칠 것**: 위에서 본 판을 펼친 채 창 크기나 화면 방향을 바꾸면 칸 자리·칸 크기·옮기기 방향을 **바뀌기 전 무대 크기로** 정한다(`play-free-build.js` `onResize`의 rAF가 무대의 `ResizeObserver`보다 먼저 돌아 `view.getSize()`가 옛 값). 예: 크롬북 창 1366×680 → 683×680에서 펼친 칸 넘침 122px·못 보는 칸 25(닫았다 열면 맞음). 무대 크기가 다시 재진 뒤에 배치하도록(무대의 크기 바뀜 알림을 받거나 매트를 직접 재기). 화면 방향 바꾸기(세로 태블릿 ↔ 가로)와 창 반으로 줄이기·되돌리기를 펼친 채로 하는 e2e를 더한다(넘침 0·못 보는 칸 0·알림 밑 버튼 0).
