# Build 서브에이전트 지침: 1차 재검토 참고 사항 수정 (N1~N4)

## 역할

너는 1차를 만든 **Build** 담당이다. [review.md](review.md) 맨 아래 "재검토 (수정 확인)"의 새 문제 N1~N4를 고친다.
사용자가 "바로 고쳐줘"라고 승인했다. 판정 로직(`fold.js`의 결과)은 바꾸지 않는다.

## 고칠 것

| # | 문제 | 고칠 방향 |
| --- | --- | --- |
| N1 | 2×2 덩어리 장면에서 65° 접힌 면 1~2개가 기본 시점에서 덩어리 뒤에 가려 안 보임 (시드 1~40 중 19장면) | 2×2 전개도도 `displayNet`에서 돌림(`turn`)이나 바닥 면을 골라, 접힌 면이 앞·왼쪽(보는 쪽)에 오게 한다. 단위 테스트로 "2×2 장면에서 모든 면이 보이는 쪽을 향함(법선·위치 기준)"을 검사 |
| N2 | 휴대폰에서 위로 옮긴 토스트가 [소리]·[← 단계 선택] 버튼을 가림 | 휴대폰에서 토스트를 머리(topbar·play-header) 아래에 띄운다 |
| N3 | 빈 자리가 기본 시점에서 안 보일 때(빈 자리가 겹친 자리 정반대) 돌려 보라는 안내 없음 | 그 경우에만 배지나 까닭 칸에 "↻ 돌려 보면 빈 자리가 보여요"를 덧붙인다. 가능하면 [↻] 버튼을 잠깐 강조 |
| N4 | 1366×680에서 아래쪽 토스트가 [다음 문제 ▶] 아래 14px를 가림 | 넓은 화면에서 이 게임의 토스트를 무대 쪽(왼쪽 아래)으로 옮기거나 문제 판과 겹치지 않게 한다 |
