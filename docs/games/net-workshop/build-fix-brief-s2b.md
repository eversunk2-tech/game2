# Build 서브에이전트 지침: S2 쌓기나무 3·4차시 — 검토 반영 (트랙 "blocks", S2b)

## 역할

너는 S2(쌓기나무 3·4차시)를 만든 **Build** 담당이다. 네 작업 폴더의 `docs/games/net-workshop/review-blocks-s2.md`(Review가 쓴 검토 결과)를 반영한다. 판정은 **"수정 필요 — 반드시 수정 1건"**(S2-1)이었고, 수학·판정(독립 계산 어긋남 0), 조작(네 수단), 정답 노출(360화면 0), 별·점수, 배치(3,456장면), 기존 차시 불변, 느린 기기는 통과했다 — 그대로 둔다. 검증은 별도 Review 서브에이전트가 다시 한다.

## 반드시 지킬 것

- 통과한 것을 깨지 않는다: 판정 독립 계산 어긋남 0, 정답 노출 0(보기의 자리·값의 꼴 — S2-2를 바꾸면 다시 잰다), 별·점수 = 독립 계산, 네 크기 배치, 기존 차시 불변, 느린 기기, 조작.
- 처음 화면·[시작하기]·단계 지도를 거치는 쌓기나무 검사 넷("단계 지도: 쌓기나무 네 차시가…" 등)은 **이번에도 건드리지 않는다** — 다음 Build(B0c)가 새 처음 화면에 맞게 고친다. 새 검사는 `?lesson=`·`?stage=`로 바로 들어가게.
- 브라우저 검사는 느린 기기를 견디게(움직임이 끝난 뒤, 사라지는 알림은 조작 바로 뒤, 머무는 시간, 시간 예산), `waitForTimeout`·`retries` 금지. 끝내기 전에 CPU 느리게 하기 4·8·12배로 쌓기나무 검사 값 실패 0.
- 테스트: `npm test`, `npm run test:e2e -- --workers=4`, `E2E_WIDE_TEXT=font npm run test:e2e -- --workers=4` 모두 실패 0(이 가지 기준 — 아직 영역 화면이 합쳐지지 않은 가지다).
