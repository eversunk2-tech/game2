# Review 서브에이전트 지침: c5 "주사위 전개도 장인"·"주사위 전개도 주문" (트랙 "c1" 작업 폴더)

## 역할과 범위

- 너는 **Review** 담당이다. Build가 [build-brief-c5.md](build-brief-c5.md)에 따라 고친 것을 **독립적으로** 확인한다. 결과는 새 파일 `docs/games/net-workshop/review-c5.md`(작업 폴더 안) 하나, 맨 위에 판정 줄. 커밋하지 않는다. 코드·테스트·다른 문서 수정 금지, 작업 트리를 바꾸는 git 명령 금지(읽기용은 된다). `npm install`·`npm ci`·내려받기 금지. 서버·실행은 네 PID만.

## 확인할 것

1. 화면에 보이는 모든 곳에 "주사위 장인"·"주사위 주문"이 남지 않았는지 — 빌드 결과물(`dist/`) 전체에서 그 글자를 찾고, 다섯 크기에서 단계 지도·도전 칸·도장판·결과 화면·학습 기록·놀이 방법·화면 읽기 이름을 직접 연다. 새 이름이 [spec.md](spec.md) 16-18의 사용자 결정 그대로인지, 도장 설명이 무엇을 하면 받는지 분명한지(해요체).
2. 저장 열쇠·id 그대로 — 옛 저장 값(도장을 받은 상태)으로 열면 새 이름으로 보이고 별·도장이 그대로.
3. 이름 말고 바뀐 것 0 — `git diff <기준>..HEAD`를 줄마다 읽고, 기준 `main` 빌드와 화면 비교(이름 자리 말고 같음).
4. 다섯 크기(1366×768·1366×680·1024×768·820×1180·390×844) × 보통·글꼴 흉내에서 긴 이름 때문에 넘침·잘림·줄바꿈 어색함 0.
5. 테스트: `npm test`, `E2E_PORT=<네 포트> npm run test:e2e -- --workers=4`, 글꼴 흉내 같은 방법 — 실패 0, 약해진 검사 0.
6. `git merge-tree --write-tree`로 `main`·`track/blocks`(R1 Review 중)·`track/cuboid`(G1b 재검토 중)와 충돌.

## 형식

판정 줄, 테스트 결과 표, 남은 옛 이름 찾기 결과, 발견한 문제 표, 확인하지 못한 것. 최종 답변 **8줄 이하**.
