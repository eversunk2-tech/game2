# Build 서브에이전트 지침: G1 각기둥 1 — 검토 반영 (트랙 "cuboid" 작업 폴더, G1b)

## 역할

너는 G1을 만든 **Build** 담당이다. 네 작업 폴더의 `docs/games/net-workshop/review-prism-g1.md`(Review가 쓴 검토 결과 — 판정 **"수정 필요"**)와 사용자 결정([spec-grade6.md](spec-grade6.md) **15-20**)을 반영한다. 판정·점수·정답 노출·배치·불변·느린 기기는 통과했다 — 그대로 둔다. 검증은 별도 Review 서브에이전트가 다시 한다.

## 반드시 지킬 것

- 통과한 것을 깨지 않는다: 판정·까닭 칩·맞닿는 선분 독립 계산 어긋남 0, 정답 노출 0(답하기 전 한 가지 모습, 잠금), 점수 = 독립 계산(모두 맞히면 64점 — G1-4·G1-5로 문항이 바뀌어도 점수 규칙 그대로), 여섯 크기 × 두 모드 배치, 키보드만으로 세 단계, 접기 프레임, 정육면체·직육면체·쌓기나무 불변, 엔진 0줄.
- [common-rules.md](common-rules.md) 전부. 브라우저 검사는 느린 기기를 견디게, `waitForTimeout`·`retries` 금지. 끝내기 전에 CPU 4·8·12배로 새로 만들거나 고친 검사 값 실패 0.
- 테스트: `npm test`, `E2E_PORT=5361 npm run test:e2e -- --workers=4`, `E2E_PORT=5361 E2E_WIDE_TEXT=font npm run test:e2e -- --workers=4` 모두 실패 0.
- 고쳐도 되는 파일은 [build-brief-g1.md](build-brief-g1.md)와 같다. `main.js`는 각기둥 줄만(S3가 쌓기나무·도장 줄을 고쳤다 — 합칠 때 충돌 없게).

## 지킬 것

- 작업 폴더·브랜치·포트·scratchpad는 지난번과 같다(`.worktrees/cuboid`, `track/cuboid`, 5301·5361·5362, `build-g1/`). 커밋은 `track/cuboid`에만, 푸시·합치기 금지. `npm install`·`npm ci`·내려받기 금지. **서버·실행을 내릴 때는 네가 띄운 PID만**.
