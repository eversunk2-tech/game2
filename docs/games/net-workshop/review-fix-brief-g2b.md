# Review 재확인 지침: G2b 각기둥 4단계·도전 고치기 (트랙 "cuboid" 작업 폴더)

## 역할과 범위

- 너는 G2를 검토한 **Review** 담당이다. Build가 [build-fix-brief-g2b.md](build-fix-brief-g2b.md)(덧붙임 포함)에 따라 고친 것을 독립적으로 다시 확인한다.
- 결과는 [review-prism-g2.md](review-prism-g2.md)(작업 폴더) 맨 아래에 **"재검토 (날짜)" 절**을 덧붙이고 맨 위 판정 줄을 새 판정으로 바꾼다(지난 판정은 재검토 절에 남김). 커밋하지 않는다. 지난번과 같은 금지·포트·scratchpad 규칙.

## 확인할 것

1. **G2-1·G2-4·R7**: 시드 3,000개 이상으로 도전 셈 문항의 정답 자리 고름, 자리·값·꼴만 보고 고르는 규칙(지워 가며 고르기·첫째 빼기·가장 작은 것 빼기·n의 배수·간격·값 빈도 등 — 네가 따로 짠 규칙 포함) 모두 ~36% 아래, 흔한 실수 n이 판마다 꼭 한 번, 모서리 문항의 2n, 정답 노출 0 — 저장소 코드를 쓰지 않은 독립 계산으로.
2. **G2-2**: 여섯 크기 × 보통·글꼴 흉내 × 2·3가지를 찾은 장면(여러 시드) 스크롤·넘침 0.
3. **G2-3**: 점수 — 처음 10가지 제 점수, 11~30번째 +1, 31번째부터 0, 이 단계 최대 104점, 화면 = 저장 = 독립 계산(일부러 틀려 이득 0, 같은 모양 두 번 점수 0). 직육면체 점수 규칙 그대로.
4. **G2-5**: 참인 까닭이 둘인 판에서 고른 까닭의 문장·표시가 먼저 보이는지. 다른 단계의 까닭 고르기는 그대로.
5. **테스트**: 셋 다 직접 실행 — 실패 0. 지난 검토 뒤 바뀐 `tests/`를 줄마다 읽어 약해진 검사 0, 새 검사가 지난 실패를 실제로 잡는지(고치기 전 `11dcfa6` 복사본에서). 새로 만들거나 고친 검사를 CPU 4·8·12배로 — 값 실패 0.
6. **불변**: 지난번처럼 다른 화면이 기준(`main` `98524f0`)과 같은지(의도한 차이만), G2의 다른 조작·배치가 지난 검토와 같은지.
7. 새로 생긴 문제.
