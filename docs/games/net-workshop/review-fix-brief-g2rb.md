# Review 재확인 지침: G2rb 각기둥 4단계 자유 배치 고치기 (트랙 "cuboid" 작업 폴더)

## 역할과 범위

- 너는 G2r을 검토한 **Review** 담당이다. Build가 [build-fix-brief-g2rb.md](build-fix-brief-g2rb.md)에 따라 고친 것을 독립적으로 다시 확인한다.
- 결과는 [review-prism-g2r.md](review-prism-g2r.md)(작업 폴더) 맨 아래에 **"재검토 (날짜)" 절**을 덧붙이고 맨 위 판정 줄을 새 판정으로 바꾼다. 커밋하지 않는다. 지난번과 같은 금지·포트·scratchpad 규칙.

## 확인할 것

1. **G2r-1**: 같은 길이가 어긋난 판에서 "어긋나게 붙어 있어요"(직육면체와 같은 문장)가 나오고 "길이가 달라요"가 거짓으로 나오지 않는지, 길이가 정말 다른 곳이 먼저 보이는지 — 학생처럼 놓은 판 수천 개로 독립 계산과 견줌(지난번 18,000판 가운데 34판이 틀렸던 꼴 포함).
2. **G2r-2**: 빈 판 누르기가 직육면체와 같은 뜻·알림인지(카드 고르지 않음 → 앞의 카드가 그 자리에, 가까운 모서리에 자석), 휴대폰 안내 띠와 맞는지, 손짓 20가지 비교를 다시 해서 다른 것 0.
3. **G2r-3~5(·6·7)**: 육각기둥 옆면 누르는 곳 48px(여섯 크기), 빗변의 30° 두 단계 모두에서 붙는지, 빗변 가운데 맞춤 비율 — 지난번 값과 견줌.
4. **테스트**: 셋 다 직접 실행 — 실패 0. 지난 검토 뒤 바뀐 `tests/`를 줄마다 읽어 약해진 검사 0, 새 검사가 지난 실패를 실제로 잡는지(고치기 전 `8ff77a1` 복사본에서). 고친 검사 CPU 4·8·12배 — 값 실패 0.
5. **불변**: 지난번처럼 다른 화면이 기준(`d2738ee`)과 같은지(의도한 차이만), 판정·점수·962가지·정답 노출이 지난 검토 값과 같은지.
6. 새로 생긴 문제.
