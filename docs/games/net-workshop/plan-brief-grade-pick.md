# 시안 서브에이전트 지침: 학년 고르기 화면 — 학년 선택이 더 눈에 띄게 (시안 셋)

## 역할

너는 **시안(Plan)** 담당이다. 저장소의 코드는 고치지 않는다. 실제 게임 화면에 CSS·요소 손질을 덧씌워 찍은 **시안 그림 셋**과 짧은 설명을 만든다. 사용자가 그중 하나를 고르면 그다음 Build가 만든다.

사용자의 말(학년 고르기 화면을 캡처해 보이며, 2026-10-17): "학년 선택이 더 눈에 잘 띌 수 있도록 변경해서 시안 3개를 나에게 보여줘"

## 지금 화면 (1366×768 크롬북 기준 — 사용자가 캡처한 것)

- 왼쪽 위 [← 처음으로] + "5·6학년 수학 · 전개도와 쌓기나무" 띠, 그 아래 아주 큰 제목 "입체도형 공방"과 소개 두 줄.
- 그 아래 학년 카드 둘(5학년 "정육면체, 직육면체 전개도 탐구" · 6학년 "각기둥의 전개도, 쌓기나무 탐구, 원기둥의 전개도 탐구" — 설명은 사용자 문장 그대로, 바꾸지 않는다) — 별 수, "여기부터!" 표지.
- 그 아래 칭호 카드(견습생, 다음 칭호까지, 별·도감·도장)와 [놀이 방법]·[학습 기록].
- 오른쪽 절반은 초록 매트 위 전개도 그림(가~바)과 "먼저 예측하고 접어서 확인!" 쪽지.
- 문제: 큰 제목·소개·전개도 그림·칭호 카드가 학년 카드와 눈길을 다툰다. 학년 카드가 화면에서 작고 아래쪽이다. 인트로에서 이미 큰 제목을 봤다.
- 곧 더해지는 것(다른 Build B0d가 만드는 중 — 시안에 자리만 그려 넣는다): 한쪽 구석의 작은 [선생님용 안내] 버튼, 맨 아래 작은 `© 2026 PSC. All rights reserved.`

## 만들 것

1. **서로 다른 방향의 시안 셋**(A·B·C). 예시 방향(그대로 따르지 않아도 됨):
   - 학년 카드를 크게·위로: 화면 가운데 큰 두 칸(큰 "5"·"6" 숫자, 학년마다 색), 큰 제목·소개는 작게 줄이거나 띠 한 줄로, 칭호 카드는 작게 아래로.
   - 물음을 앞세우기: "몇 학년이에요?"류 큰 물음 + 그 아래 학년 버튼 둘, 오른쪽 그림은 작게.
   - 그림과 함께: 오른쪽 매트 위에 학년 카드를 올려 그림 자체가 고르는 판이 되게 등.
   세 시안 모두: 학년 설명 글은 사용자 문장 그대로, "여기부터!"·별 수·칭호·[놀이 방법]·[학습 기록]·[← 처음으로]·소리 버튼은 남긴다(자리·크기는 바꿔도 됨). 디자인 바탕("종이 공방" — `docs/design/spec.md`, 디자인 토큰, 제목 글꼴 Do Hyeon)을 따른다. 새 그림 파일·바깥 글꼴·이모지 금지. 손가락 48px, 글자 대비 4.5:1(큰 글자 3:1).
2. **찍는 방법**: 이 컴퓨터의 `main`(지금 커밋 — 코디네이터가 알려 줌)을 scratchpad에 `git archive`로 풀어 `node_modules`를 링크하고 빌드한 뒤, 그 `dist/`를 작은 서버(scratchpad)로 열어 학년 고르기 화면(`net-workshop.html?intro=0`이 아직 없으면 인트로에서 [입장하기])에서 Playwright로 CSS(`addStyleTag`)·요소 손질(`evaluate`)을 덧씌워 찍는다. 움직임 줄이기로 연 화면. 저장소 파일·작업 폴더는 건드리지 않는다.
3. **크기**: 시안마다 1366×768@1(크롬북 — 가장 중요), 820×1180@2(태블릿 세로), 390×844@3(휴대폰) 세 장. 그리고 1366×768 넷(지금 + A·B·C)을 2×2로 붙인 **비교 한 장**(각 칸 위에 "지금 / A / B / C"와 한 줄 이름). 비교 그림 파일은 PNG.
4. 시안마다 잰 것: 학년 카드의 크기(px)와 화면에서 차지하는 비율, 첫 눈에 들어오는 순서(자리·크기로 본 의견), 스크롤 생김 여부, 글꼴 흉내(`E2E_WIDE_TEXT=font`와 같은 넓은 글자 — `tests/e2e/helpers.js`의 `wideTextCss()`를 덧씌워 한 번)에서 넘침.
5. 시안마다 **만들 때 바뀌는 것**(엔진 `src/shared/ui/app.js`의 학년 고르기 화면·`base.css`·게임 `style.css` 가운데 어디를 얼마나 — 추정), 좋은 점·걱정되는 점, 그리고 **추천 하나와 까닭**.

## 지킬 것

- 저장소 코드·문서를 고치지 않는다. 커밋·작업 트리를 바꾸는 git 명령 금지(읽기용·`git archive`는 된다). `npm install`·`npm ci`·내려받기 금지.
- scratchpad `design-grade/`(코디네이터가 경로를 알려 준다)에만 쓴다. 포트 **5341**(필요하면 5342). **서버를 내릴 때는 네가 띄운 PID만**(`pkill -f`·`killall` 금지). 다른 일이 같은 때에 돈다(포트 5304~5309·5314~5319·5325~5329·4173) — 건드리지 않는다.
- 교과서·다른 게임의 그림·문장을 옮기지 않는다(공개 저장소).

## 최종 보고 (10줄 이하)

비교 그림 경로, 시안 A·B·C 한 줄 이름과 핵심 바뀜, 각 시안의 학년 카드 크기·비율, 휴대폰·태블릿에서의 모습, 넘침, 만들 때 바뀌는 곳(추정), 추천과 까닭, 모든 그림 경로. 직접 찍어 본 것과 추정을 구분한다.
