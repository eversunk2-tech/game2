## 시안과 비교

크기 4가지(1366×768, 1366×680, 820×1180, 390×844)로 게임 모음, net-workshop(처음 화면, 단계 지도, 판별·마주 보는 면·면 붙이기, 판별 오답, 결과, 학습 기록), 예시 게임(처음 화면, 단계 지도, 플레이, 오답·정답 토스트)을 찍었다(`shots/`). 시안 `01`·`02`·`02-tablet`·`03-680`·`06`·`07`·`08`과 나란히 놓고 비교했다.

- **같다**: 종이 바탕 모눈, 잉크 테두리 + 단단한 그림자 버튼(누르면 내려앉음), 형광펜 h1, 2단 히어로(매트·자·색종이 조각), 차시 판("1차시" 잉크 칩 + h3 + 시간 칩), 점선 길로 이은 단계 카드(번호 메달, ✓ 마쳤어요 / ⚑ 지금 할 곳 + "여기부터!" + [시작 ▶] / 점선·자물쇠 잠김), 태블릿 2열, 한 줄 플레이 머리(← 단계 선택 · 제목 + 노랑 칩 · 목표), 무대 아래 가운데 토스트, 증명서(테이프 + 도장 + 큰 별 + 별 기준 안내 + 통계 + 버튼) + 오른쪽 "다시 살펴볼 점", 학습 기록(요약 4칸·표·자주 틀린 개념·아래 이름 칸), 게임 모음(약속 칩 3개, 가로형 카드, 표지·상태 띠, 아이콘 붙은 단원·시간·방식, 아래 쪽지 2개). 승인한 모습과 크게 다른 곳은 없다.
- **시안과 다르지만 범위상 맞다(D2·N1)**: 칭호 칩·내 공방 카드·도감/도장 수·도전 주문서·오늘의 솜씨·칭호 카드·색종이·도장판·[도감 보기], 플레이 머리 오른쪽 상자(`.play-meta` 빈 자리). net-workshop의 매트 무대·작업 지시서 판·"내 답" 꼬리표·단계 그림(`thumb`)·히어로 그림은 N1. net-workshop 답 버튼의 이모지 ⭕❌와 ↺↻도 N1에서 아이콘으로 바꿀 것(지금은 기기 글꼴로 그려짐).
- **작은 차이**: 머리 상징이 첫 글자(문제 7). 시간 칩이 "약 10분"(시안 "10분 안팎"). 거르기 칩은 게임이 4개 이상일 때만 보임(기획서 규칙대로, 시안은 2개인데도 보임). 게임 모음 쪽지에 `?fx=low`가 없음(아직 기능이 없으니 맞음). "여기부터!" 깃발이 `thumb` 그림 위쪽 끝에 살짝 닿음(시안도 비슷함). 제목 글꼴이 Jua에서 Do Hyeon으로 바뀐 것은 승인한 결정이다.

## 확인한 것 (문제없음)

- **범위**: 바뀐 파일은 모두 build-brief 허용 목록 안이다. `game.json`은 `color`만 더했다. net-workshop은 `style.css`(답 버튼 비활성 모양 맞춤, 자체 토스트 위치 규칙을 지우고 `feedback.anchor`로 대체), `view3d.js`(+2줄 `ctx.feedback.anchor?.(view.el)`)뿐이다. `_template`·`fold.js`·`logic.js`·`docs/games/**`·`CLAUDE.md`·`spec.md`·`.github`·`.claude`는 변경 없다. `src/shared/core/*`(기존 파일)·`dom.js`·`drag-drop.js`·`audio.js`도 변경 없다. devDependency는 `@expo-google-fonts/do-hyeon@0.4.1`·`subset-font@2.9.0` 정확한 버전이고, lock은 추가만 있다.
- **D2 범위가 들어오지 않음**: 점수·칭호·연속·도장판·도감·색종이·`?fx=low` 코드가 없다(검색 결과 주석 1줄뿐).
- **결과 화면 정적 도장 의견: D1에 있어도 된다.** 기획서 3절 공통 부품 표에 "결과 도장 문구"가 따로 있고, 승인 시안 06에도 있다. 별 개수(이미 있는 값)로 문구만 고르고 저장·점수·조건 판정이 없으며 `aria-hidden`이다. 따라서 4절의 보상 체계(도장판·업적)가 아니라 결과 화면 틀의 일부다. build-brief의 "도장은 D2"와 겹쳐 읽힐 수 있으니, D2 지침에 "결과 도장은 D1에 있음, 연출만 더함"을 적어 두면 좋다.
- **하위 호환(5-2·5-3)**: 기존 e2e를 고치지 않고 모두 통과한다. 옛 변수 9개는 모두 남아 있다. 지운 클래스(`stage-grid`, `stat-sub`, `.stars .off`, `screen-title` 스타일)는 어느 게임도 쓰지 않는다. h1 접근 이름이 같고, 단계 카드 순서·`disabled`, `.lesson-group h3`, `.eyebrow`(`?lesson`이면 차시 제목), 결과 제목, "n번 중 m번 맞힘", 버튼 이름이 유지된다. `?unlock ?stage ?sound ?seed ?lesson`은 e2e로, `show()` 뒤 토스트 자리 초기화는 직접 확인했다. 예시 게임은 `main.js`를 고치지 않았고 새 모습이 저절로 붙는다.
- **선택 인자**(e2e 없는 부분, 복사본 게임으로 직접 확인): `heroArt` 그림이 매트 가운데에 들어가고 `aria-hidden`이다. `thumb` 그림이 카드에 들어가고, `thumb`이 예외를 던지면 `console.error`만 남기고 카드는 그려진다. `chip`("검사 주문")과 기본값("2단계")이 맞게 나온다. `feedback.anchor`는 토스트 가운데 x가 요소 가운데와 같다(443 = 443)는 것, 화면을 바꾸면 기본 자리(683, 아래 24px)로 돌아온다는 것을 확인했다.
- **글꼴**: 빌드 파일 3개에 바깥 참조가 없다. 남은 `http`는 SVG 이름공간 문자열뿐이고, 실행 중 `file:`·`data:` 밖 요청 0건(게임 모음·두 게임 전체 흐름). 62개 장면(오답·정답·힌트·다시 하기·결과 3종·실패·기록·지우기 확인 포함)에서 제목 글꼴로 그려진 글자 2,740개를 넣은 글꼴의 cmap과 대조했다. **잘라 넣은 글꼴에 빠진 글자 0**. Do Hyeon 자체에 없는 것은 `·`(문제 2)와 net-workshop의 이모지·↺↻뿐이다. 동적으로 글자를 만드는 코드(`fromCharCode`·`Intl`·`toLocale*`·`\u` 이스케이프)는 없다. 개발 서버에서 `/__fonts/display.css`·`display.ttf`(858 KB)가 제공되고, 게임 모음·두 게임·템플릿 h1이 Do Hyeon으로 그려진다(`document.fonts` loaded, CDP 확인). OFL: `src/shared/fonts/OFL.txt`는 패키지의 `LICENSE_FONT`와 같고, 예약 글꼴 이름이 없다. 넣은 글꼴 안에 name 0(저작권)·1~6·13(라이선스)·14(URL)가 남아 있고, `@font-face` 앞에 `/*! … Copyright … SIL Open Font License 1.1 */` 주석이 있다.

### 확인한 것 (문제없음)

- **범위**: 바뀐 파일은 모두 build-brief-d2 허용 목록 안이다. 예시 게임·템플릿·`package.json`·`package-lock.json`·net-workshop의 `style.css` 밖 파일·`net-workshop.spec.js`·`smoke.spec.js`는 변경 없다. 전개도 고유 보상(칭호 이름·게임 도장·도감 2개·자유 배치·주문 내용)은 없다. net-workshop은 엔진 기본(새싹~으뜸 박사)으로 돈다.
- **기획서 4절과 대조**: 점수 표 10줄, 칭호 기준 0·40·100·180·300과 이름 5개, 기본 도장 6개의 조건, 연속 2 이상일 때만 표시, 3번마다 +1 + `combo` 음 높이, 도전 주문서(차시의 일반 단계를 모두 마치면 열림, 다음 단계를 막지 않음, 모은 별 합계 밖, `?stage=`로 잠긴 도전 단계를 열 수 없음), 효과음 10가지 모양과 음량 상한 0.18, 결과 복사 한 줄("칭호: 새싹(32점) · 도장 2개"), 저장 모양(`rewards {v,xp,badges,counters,best,rank}`·`collections`) 모두 맞다. 도전 성공 +10이 단계 완료 +5를 **대신하는** 것은 기획서가 정하지 않은 부분인데, engine.md에 적혀 있다.
- **하위 호환**: 예시 게임은 코드 수정 없이 점수·칭호·도장이 붙고, 기존 e2e는 고치지 않고 통과한다. `ctx.feedback`은 복사본이지만 `anchor`·`mark` 등 기존 이름이 그대로라 net-workshop이 그대로 돈다. `createProgress`는 `optionalIds`가 없으면 잠금·다음 단계가 이전과 같다(단위 테스트, e2e). `rewards.off`면 칭호 칩·점수 상자·칭호 카드가 0개이고 `rewards` 키도 저장하지 않는다(도감은 남음). 기존 주소 옵션은 e2e로 확인했다. D1 참고 #5(템플릿 "1단계 [1단계]")도 고쳐졌다(제목과 같으면 칩·윗줄을 겹쳐 쓰지 않음).
- **저장·개인정보**: 이름을 입력하고 결과를 복사해도 저장소에는 이름이 없다. 키는 `edu:<id>:rewards/stars/log/collections`뿐이다. "기록 모두 지우기"는 점수·도장·횟수·시간 기록·도감·별·기록을 모두 비운다. 저장이 막힌 브라우저(`localStorage` 접근 자체가 예외 / `setItem`만 예외)에서도 예시 게임 1단계를 끝까지 하면 +32, 도장 2개가 나오고 오류는 0이다.
- **축하 연출·접근성**:
  - 보통 설정: 결과 색종이 최대 12개, 2.3초 뒤 0개, 연출 클래스가 지워진다. 플레이 중 `celebrate`는 10개 만들고 1.6초 뒤 0개.
  - 움직임 줄이기와 `?fx=low`: 결과·플레이 모두 색종이 0개, 처음부터 끝 상태. 안내 문장은 그대로 나온다.
  - Enter·Space·Esc·누르기로 바로 끝 상태가 된다. 키로 건너뛰면 초점은 결과 제목에 남는다.
  - `role="status"` 안내 예: "별 3개 중 1개. 솜씨 점수 25점을 모았어요. 칭호가 올랐어요: 탐험가. 새 도장: 끝까지 다시, 다시 일어서기, 차시 완주. 도전 주문서 2개가 열렸어요"
  - 화면을 바꾸면 남은 타이머 5개가 0개로 정리된다.
- **대비·48px·스크롤**:
  - 대비: D2 화면의 글자 238곳이 모두 기준 이상이다(표지 SVG 오탐 5곳 제외, D1과 같음). 새 토큰 쌍 최저는 `--stamp`/종이 5.24, 잠긴 도장 테두리 4.47(그림 기준 3:1 이상).
  - 48px: 4가지 크기에서 48px 미만인 누르는 것이 없다.
  - 세로 스크롤 0: 1366×768·1366×680에서 예시·전개도·시험 페이지의 플레이(연속·점수 상자 포함)와 결과(가장 꽉 찬 경우 포함). 820×1180은 문제 #4의 한 경우만 56px. 학습 기록은 스크롤 허용 화면이다.
  - 가로 스크롤은 모든 화면·크기에서 0이다.
- **성능**(CPU 6배·4배):
  - 결과 연출 2.5초 동안 평균 프레임은 17.0~17.9ms이고, 50ms를 넘는 프레임은 결과 화면을 만드는 순간의 1개뿐이다(6배 117~183ms, 4배 67ms. D1 빌드는 이 전환에서 33ms 이하).
  - 색종이·별·도장·막대는 `transform`·`opacity`만 움직인다(막대는 `scaleX`).
- **효과음**: `?sound=off`로 예시 1단계를 결과 연출 끝까지 해도 만든 발진기·잡음은 0개다(소리를 켜면 53개).
- **코드·문서**:
  - `innerHTML`은 없다. 점수·칭호·도장·도감 판정은 `core/rewards.js`·`core/collection.js`의 순수 함수다.
  - engine.md 10절(점수 표, 중간에 나가면 저장 안 함, 새로 찾음만 바로 저장, `highlights`는 보여 주기만, 도전 +10 대신, 연출 시간, `peek`)은 실제 동작과 맞다. 다만 문제 #2의 `explain` 설명은 고쳐야 한다.
  - dev-guide·README의 보상 원칙 문장도 실제 동작과 맞다.
- **콘솔 오류·정답 노출**: 모든 검증 실행에서 `pageerror`·`console.error`는 0건이다. 일부러 넣은 예외만 나왔다. net-workshop 세 단계에서 답하기 전 DOM에 정답을 알 수 있는 속성이 없다. 새로 생긴 것은 숨겨진 연속 상자뿐이다.

### 시안과 비교

시안 `01`(내 공방 카드), `02`(도전 주문서 줄), `06`(결과 축하), `08`(학습 기록·도장판)과 실제 화면을 나란히 봤다(`shots/s-*.png`, `1366x*-*.png`).

- 내 공방 카드(칭호 도장·점수 막대·별·도감·도장 수), 머리 칭호 칩, 도전 주문서 줄(빨간 "도전" 도장 카드, "차시를 마치면 열려요 / 하고 싶은 사람만 · 시간 제한 없음"), 결과의 오늘의 솜씨 3칸과 점수 줄, 칭호 카드(새 칭호 도장·막대)·새 도장 카드·"도전 주문서 n개가 열렸어요" 칩, 도장판(받은 것은 빨간 도장, 못 받은 것은 점선 원 + "?" + 받는 방법)이 시안과 같은 구성이다.
- 다른 점: 문제 #6. 휴대폰에서는 칭호 칩이 도장만 보이고 연속·점수 상자가 숨는다(결과에는 나옴). 도감 화면은 시안에 없어 새로 만들었다. 전개도 고유 칭호·도장·도감 그림은 N1이다.

### 확인하지 못한 것

- 실제 크롬북(코어 2개 자동 `fx=low` 포함)·태블릿에서 본 모습과 소리. 소리는 만든 발진기 수로만 확인했고 들어 보지는 않았다.
