## 3. `main`에 합칠 때 할 일 (다음에도 그대로 쓴다)

- 합치기·푸시는 코디네이터만 한다. 트랙의 Review가 통과하면 그 트랙의 `review-<트랙>.md`를 트랙 브랜치에 커밋하고 `main`에 `--no-ff`로 합친다.
- 합친 뒤 전체 테스트를 처음부터 다시 돌린다: `npm test`, `npm run test:e2e`, `E2E_WIDE_TEXT=font npm run test:e2e`. 다른 서브에이전트가 테스트를 돌리는 중이면 컴퓨터가 느려 전부터 흔들리던 검사가 실패할 수 있다 — 혼자 다시 돌려 가리고, **새로 합친 것의 검사가 실패하면 올리지 않는다**(2026-10-12에 쌓기나무를 이 때문에 하루 붙잡았다).
- 합친 화면을 한 번 직접 연다(단계 지도에 차시가 제대로 이어지는지, 콘솔 오류 0).
- 푸시한 뒤 GitHub Actions의 배포·CI 결과를 확인한다.
- 이 문서와 [HANDOFF.md](HANDOFF.md)의 "끝난 것"을 고친다.
