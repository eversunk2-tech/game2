# 2022 개정 5~6학년 학습게임 기획 제안 (인수인계용)

작성일: 2026-10-07
목적: 클라우드 세션에서 웹 기반 학습게임을 개발하기 위한 교과·주제·게임 형태 후보 정리. 사용자가 후보 중 선택하면 기획서 작성으로 이어감.

## 1. 조사 요약

- 2022 개정 교육과정은 2026학년도부터 초등 5·6학년에 적용.
- 단원·성취기준 출처: 경기도교육청 「2026학년도 초등학교 5~6학년 1~2학기 수업-평가 계획 예시자료」(성취기준·단원 연결표).
- 기존 학습게임 유형
  - 퀴즈 래퍼형 (Kahoot: 라이브 퀴즈+리더보드 / Gimkit: 게임 내 화폐·파워업 / Blooket: 다양한 모드) → 복습용, 개념 학습에는 한계
  - 플레이 자체가 학습인 게임 (Legends of Learning: instructional / quiz / PhET 시뮬레이션, DragonBox: 기호 전에 개념 먼저)
  - RPG 래퍼형 (Prodigy)
  - 국내: 문체부·경기도 교과학습용 기능성게임(5학년 과학 레이싱 'STEAM Challenge', 3학년 수학 '수학의 왕'), 교사 바이브코딩 사례(서울서이초 반려견 돌봄 시뮬레이션, 5학년 실과), 네오버스(작품 공유 플랫폼)
- 효과: 2024 메타분석에서 디지털 게임 기반 학습이 중간 정도 효과(인지 영역에서 더 큼). 단, 출처가 Prodigy 블로그이므로 참고용.

## 2. 선정 기준

1. 교실에서 직접 하기 어렵거나 위험한 활동
2. 학생이 자주 막히는 개념 (예: 5학년 분모가 다른 분수 계산)
3. 변인 조작·시행착오가 핵심인 학습

## 3. 제안 목록

### A. 수학: 개념을 직접 조작하는 퍼즐·시뮬레이션
1. **분수 공장** — 5-1 약분과 통분·분수의 덧셈과 뺄셈, 5-2 분수의 곱셈, 6학년 분수의 나눗셈 / 퍼즐 / 띠·영역 모델 조각을 쪼개고 합쳐 주문서의 분수를 맞춤. 기호는 나중에 등장.
2. **약수·배수 톱니바퀴** — 5-1 약수와 배수 / 퍼즐+리듬 / 서로 다른 속도의 톱니가 다시 만나는 순간=최소공배수, "남김없이 나눠 담기" 스테이지=최대공약수.
3. **비율 카페 사장** — 6-1 비와 비율, 6-2 비례식과 비례배분 / 경영 시뮬레이션 / 레시피 비율, 할인율·백분율 가격표, 비례배분으로 수익 나누기.
4. **전개도 접기 공방** — 5-2 직육면체·정육면체, 6-1 각기둥·각뿔, 6-2 원기둥·원뿔·구, 공간과 입체 / 3D 퍼즐 / 전개도를 접어 입체 완성, 접히지 않는 전개도 판별.
5. **부피 건축가** — 6-1 직육면체의 겉넓이와 부피, 6-2 공간과 입체 / 샌드박스+도전 과제 / 같은 부피로 겉넓이 최소화(포장비 절감).

### B. 과학: 가상 실험실과 설계
6. **용액 탐정 연구소** — 5-1 용해와 용액, 6-1 산과 염기 / 가상 실험실+미스터리 / 정체불명 용액을 변인 통제 실험으로 추리.
7. **단열 도시락 설계소** — 5-2 열과 우리 생활 / 설계-테스트-개선 / 재료·두께·뚜껑 조합, 시간별 온도 그래프.
8. **속력 레이싱** — 6-1 물체의 운동 / 레이싱 / 거리·시간으로 속력 계산해 구간 전략, 교통안전 이벤트.
9. **화석 발굴단** — 5-1 지층과 화석 / 탐사·방탈출 / 지층 형성, 퇴적암 분류, 화석으로 과거 환경 추리.
10. **몸속·식물 탐험대** — 5-1 우리 몸의 구조와 기능, 6-1 식물의 구조와 기능 / 축소 탐험 / 기관 연결, 물 이동·증산 경로.
- 확장 후보: 6-2 물질의 연소, 전기의 이용

### C. 사회: 추리와 롤플레이
11. **시간여행 증거 탐정** — 5-2 유적·유물로 살펴본 옛 사람들의 생활, 달라지는 시대 / 추리 / 유물·사료 카드로 시대 판별과 생활 추론.
12. **위도·경도 항해사** — 6-1 지구·대륙·국가들, 5-1 국토여행 / 항해(전함 게임 방식) / 좌표로 보물섬 찾기, 이후 국토 지형·독도로 확장.
13. **민주주의 시민 시뮬레이터** — 6-1 민주주의와 시민 참여, 5-1 법과 인권의 보장 / 롤플레이 / 모의 선거, 삼권 분립 사건 카드 분류, 사실·의견 구분.

### D. 국어·실과·도덕
14. **가짜 뉴스 편집장** — 국어 5-2 매체 신뢰성 평가, 6-1 비판적으로 읽기, 사회 6-1 미디어 / 판정 게임.
15. **AI 훈련사** — 실과 디지털 사회와 인공지능, 도덕 AI 로봇 단원 / 분류 훈련+코딩 퍼즐 / 데이터 편향 발견.
16. **관용 표현·방언 카드 배틀** — 국어 6-1 관용 표현, 5-2 표준어와 방언 / 카드 대전.

※ 영어는 2022 개정 성취기준을 확인하지 못해 제외.

## 4. 추천

- 가장 확실: 1. 분수 공장
- 차별화: 6. 용액 탐정 연구소 또는 7. 단열 도시락 설계소
- 가볍게 시작: 12. 위도·경도 항해사

## 5. 구현 메모 (클라우드 세션)

- HTML 한 파일(Canvas/SVG) 기반 2D가 가장 안정적이며 링크 하나로 학생에게 공유 가능.
- 4번·5번은 3D(Three.js)도 가능하나 작업량 증가.

## 6. 다음 단계

사용자가 번호 1~3개와 대상 학년(5학년/6학년)을 선택 → 게임 기획서(규칙·스테이지 구성·평가 요소) 작성. 한 판 길이(10분/차시 전체), 개인/모둠 여부도 함께 확정.
